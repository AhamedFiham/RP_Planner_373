Full-stack project for an AI system that helps diabetes patients.

## Project structure

- `frontend/` — Next.js application
- `backend/` — API server and database integration

## Run the frontend

```sh
npm ci --prefix frontend
npm run dev
```

Open http://127.0.0.1:3000 to go directly to the dashboard. The DFU and team sections are linked from there; no login is required.

The project-root scripts forward `dev`, `build`, and `start` to the Next.js app in `frontend/`.
If PowerShell blocks `npm.ps1`, use `npm.cmd` for these commands.
